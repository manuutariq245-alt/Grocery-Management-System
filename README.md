# Grocery Management System

A desktop-based grocery store management application developed using Python, Tkinter, and SQLite to manage products, inventory, sales, and customer billing operations.

## Features

- Product and inventory management
- SQLite database integration
- Product search
- Stock tracking
- Low-stock notifications
- Automated customer billing and bill calculation
- User-friendly graphical user interface (GUI) using Tkinter

## Technologies Used

- Python
- Tkinter
- SQLite

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file.
